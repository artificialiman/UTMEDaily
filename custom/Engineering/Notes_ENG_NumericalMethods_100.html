Engineering · Shared Core, Year 2

Numerical Methods

When an equation has no closed form, replace it with a short repeatable calculation and track the error. Each method here is one formula applied again and again. Learn the formula, how fast its error shrinks, and the condition that makes it fail. One hundred problems, every step shown.

ORIENTATION

Approximate, repeat, bound the error

Numerical methods trade an exact answer for a calculation a computer can do. Roots come from repeating a step, curves from a polynomial through the data, derivatives and integrals from sums of function values, and differential equations from small steps. Every method comes with an error order, and that order says how much a smaller step buys.

CHAPTER 1

The Ten Blocks

One card per block, with the rule and the trap to avoid.

Block 1 · Errors and conditioning

Where digits are lost

κ = |x f′ / f|
Rule: Absolute errors add in sums, relative errors add in products. Rewrite expressions to avoid cancellation.
Block 2 · Root finding

Bracket, then accelerate

x_{n+1} = x_n − f / f′
Rule: Bisection always works but is slow. Newton is quadratic but needs f′ ≠ 0. A double root slows Newton to linear.
Block 3 · Fixed-point iteration

Rearrange so |g′| < 1

x = g(x)
Rule: Error shrinks by |g′| each step. For systems, solve J d = −F.
Block 4 · Interpolation

A polynomial through the data

n + 1 points, degree n
Rule: Divided differences build the polynomial. Equal spacing at high degree oscillates; splines avoid it.
Block 5 · Numerical differentiation

Differences of function values

(f(x + h) − f(x − h)) / 2h
Rule: Central is O(h²), one-sided is O(h). Too small an h makes round-off dominate.
Block 6 · Numerical integration

Weighted sums of values

Simpson: h/3 [1, 4, 2, …, 4, 1]
Rule: Simpson needs an even number of strips. Gauss rules reach degree 2n − 1.
Block 7 · Direct linear solvers

Eliminate, factor, substitute

A = LU
Rule: Pivot on the largest entry. Work grows as n³. A zero pivot means singular.
Block 8 · Iterative linear solvers

Update until the residual is small

ρ(iteration matrix) < 1
Rule: Gauss–Seidel uses new values at once. Diagonal dominance guarantees convergence.
Block 9 · Initial value problems

Step in time

y_{n+1} = y_n + h f
Rule: Euler is O(h), Heun O(h²), RK4 O(h⁴). A step too large makes Euler unstable.
Block 10 · Fitting and boundary value problems

Least squares and finite differences

normal equations
Rule: Residuals are observed minus fitted. A boundary value problem becomes a linear system on the grid.
