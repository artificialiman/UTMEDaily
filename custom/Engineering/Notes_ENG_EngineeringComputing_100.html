Engineering · Shared Core, Year 2

Engineering Computing

A program stores numbers, combines them, repeats the combination and checks the result. Learn how a number is stored and each later step is a small trace. The language here is Python, and the same ideas carry to MATLAB, C and spreadsheets. One hundred problems, every step shown.

ORIENTATION

Store, compute, repeat, check

Every program in this course follows one chain. A value is stored in a fixed number of bits, so its range and its precision are limited. Expressions combine values in a fixed order of precedence. Loops and functions repeat the work. At the end the answer is compared with a tolerance, because stored numbers carry a small error.

CHAPTER 1

The Ten Blocks

One card per block, with the rule and the trap to avoid.

Block 1 · Number systems

Binary, hexadecimal, two’s complement

n bits give 2ⁿ values
Rule: Hexadecimal groups binary in fours. A negative number is stored by invert and add 1. Resolution is range ÷ 2ⁿ.
Block 2 · Floating point and error

Stored numbers are not exact

abs(a − b) < tolerance
Rule: A decimal like 0.1 has no exact binary form. Never test floats with ==. Subtracting close numbers loses digits.
Block 3 · Expressions and types

Trace the order of evaluation

** → * / // % → + −
Rule: / gives a float, // floors, % is the remainder. A right-hand side is fully evaluated before assignment.
Block 4 · Conditionals and logic

First true branch wins

not → and → or
Rule: Test the strictest condition first. and stops early. De Morgan turns not (A and B) into not A or not B.
Block 5 · Loops

Count the passes

range(a, b, k)
Rule: The end is excluded. A loop variable keeps its last value. Nested loops multiply; a dependent inner limit adds.
Block 6 · Lists and arrays

Index from zero

a[i:j:k]
Rule: A slice excludes the end. b = a is an alias, not a copy. A comprehension is a loop in one line.
Block 7 · Functions

Input, work, return

def f(x): return …
Rule: No return gives None. A name assigned inside is local. Recursion needs a base case.
Block 8 · Algorithms and complexity

Count the work

binary search: ⌊log₂ n⌋ + 1
Rule: Bubble sort makes n(n − 1)/2 comparisons. Binary search needs a sorted list. A work ratio follows the power of n.
Block 9 · Numerical methods

Repeat until the error is small

x_{n+1} = x_n − f/f′
Rule: Bisection halves the interval. Simpson beats the trapezoid rule. Euler’s error is proportional to the step.
Block 10 · Matrices, data and text

Rows times columns

C_ij = Σ A_ik B_kj
Rule: A matrix product is not entry by entry. Split text, then convert it to numbers. A dictionary is looked up by key.

Number systems

Questions 1–10. Convert, add and range-check in binary and hexadecimal.

Question 1
Convert 11012 to decimal.
Solution
1Weights from the right are 1, 2, 4, 8.
21 × 8 + 1 × 4 + 0 × 2 + 1 × 1 = 13.
Answer13
Common slips: The weights start at 1 on the right, not on the left; starting from the left gives 11.
Question 2
Convert 45 to binary.
Solution
1Divide by 2 repeatedly and keep the remainders: 45 → 22 r 1, 22 → 11 r 0, 11 → 5 r 1, 5 → 2 r 1, 2 → 1 r 0, 1 → 0 r 1.
2Read the remainders from last to first: 101101.
3Check: 32 + 8 + 4 + 1 = 45.
Answer1011012
Common slips: The remainders are read from last to first; reading them in the order found gives the number reversed.
Question 3
Convert 2F16 to decimal.
Solution
1Each hexadecimal digit is worth 16 times the digit to its right. F = 15.
22 × 16 + 15 = 47.
Answer47
Common slips: Using 10 instead of 16 as the weight gives 35.
Question 4
Convert 101101112 to hexadecimal.
Solution
1Group the bits in fours from the right: 1011 | 0111.
21011 = 11 = B and 0111 = 7.
AnswerB716
Common slips: Group from the right; a number whose length is not a multiple of four is padded with zeros on the left.
Question 5
Add 10112 + 01102 in binary.
Solution
1Add column by column from the right, carrying 1 when the sum reaches 2.
21 + 0 = 1; 1 + 1 = 10 (write 0, carry 1); 0 + 1 + 1 = 10 (write 0, carry 1); 1 + 0 + 1 = 10.
3The result is 100012.
4Check: 11 + 6 = 17 = 16 + 1.
Answer100012
Common slips: The carry out of the top column becomes a fifth bit.
Question 6
Write −5 as an 8-bit two’s complement number.
Solution
1+5 is 00000101.
2Invert every bit: 11111010.
3Add 1: 11111011.
Answer11111011
Common slips: Inverting alone gives the one’s complement, 11111010, which is −5 minus one in two’s complement.
Question 7
The 8-bit two’s complement number 11110000 is read as a decimal. What is it?
Solution
1The leading bit is 1, so the number is negative.
2Invert: 00001111. Add 1: 00010000 = 16.
3The value is −16.
Answer−16
Common slips: Reading it as unsigned gives 240.
Question 8
Find the smallest and largest 8-bit two’s complement integers.
Solution
1One bit is the sign, leaving 7 bits for the size.
2Largest: 01111111 = 127. Smallest: 10000000 = −128.
Answer−128 and 127
Common slips: The range is not symmetric: there is one more negative number than positive.
Question 9
How many bits are needed to store 1000 distinct values?
Solution
1n bits give 2n values.
229 = 512 is too small; 210 = 1024 is enough.
Answer10 bits
Common slips: Rounding log2 1000 = 9.97 down to 9 leaves 488 values with no code.
Question 10
A 12-bit analogue-to-digital converter measures 0 V to 5 V. Taking the step as range ÷ 212, find its resolution.
Solution
1The converter has 212 = 4096 levels.
2Step = 5 ÷ 4096 = 0.00122 V.
Answer≈ 1.22 mV

Question 11

Solution

Answer0.625

Question 12
What does this print?
print(0.1 + 0.2 == 0.3)
Solution

2Their sum is 0.30000000000000004, which is not the stored value of 0.3.
3To compare floats, test whether the difference is smaller than a tolerance.
AnswerFalse
Common slips: The test is exact; it does not allow for round-off.
Question 13
A double precision number has a 52-bit fraction. Write the gap between 1 and the next larger number it can store.
Solution
1The next number above 1 changes the last fraction bit.
2That bit is worth 2−52 ≈ 2.22 × 10−16.
Answer2−52 ≈ 2.22 × 10−16
Common slips: This is machine epsilon; it gives about 15 to 16 correct decimal digits.
Question 14
The true value is 3.14159 and an approximation is 3.14. Find the absolute and relative errors.
Solution
1Absolute error = |3.14159 − 3.14| = 0.00159.
2Relative error = 0.00159 ÷ 3.14159 = 5.06 × 10−4, that is 0.0506%.
Answer0.00159 and 0.0506%
Common slips: Relative error divides by the true value, not by the approximation.
Question 15
1/3 is stored as 0.333 (3 significant figures). Find the result of 3 × 0.333 and its error from 1.
Solution
13 × 0.333 = 0.999.
2Error = 1 − 0.999 = 0.001.
Answer0.999, error 0.001
Common slips: Round-off in each stored number carries through the arithmetic.
Question 16
Each of 0.12345678 and 0.12345600 is accurate to 8 significant figures. How many significant figures does their difference keep?
Solution
10.12345678 − 0.12345600 = 0.00000078.
2Only the digits 7 and 8 survive: 2 significant figures.
Answer2
Common slips: This loss is called subtractive cancellation; avoid subtracting two nearly equal numbers.
Question 17
Estimate e0.1 using 1 + x + x2/2 and find the truncation error. (e0.1 = 1.105171 to 6 decimals.)
Solution
11 + 0.1 + 0.005 = 1.105.
2Error = 1.105171 − 1.105 = 0.000171 ≈ 1.7 × 10−4.
3The first dropped term is x3/6 = 0.000167, which accounts for almost all of it.
Answer1.105; error ≈ 1.7 × 10−4
Common slips: Truncation error comes from the method; round-off comes from storage.
Question 18
An 8-bit unsigned counter holds 200. 100 is added to it. What does the counter now hold?
Solution
1The largest value is 255 and 200 + 100 = 300.
2The counter wraps around: 300 − 256 = 44.
Answer44
Common slips: The result is the remainder on division by 28.

What does this print?

    s += 0.1

2After ten additions the errors have built up to just under 1.

Question 20

Answer7.9

Question 71
What is the list after the first pass of bubble sort on [5, 1, 4, 2, 8]?
a = [5, 1, 4, 2, 8]
for i in range(len(a) - 1):
    if a[i] > a[i + 1]:
        a[i], a[i + 1] = a[i + 1], a[i]
print(a)
Solution
1Compare neighbours and swap if out of order: 5 > 1 swap, 5 > 4 swap, 5 > 2 swap, 5 < 8 no swap.
2The largest value of the unsorted part, 8, ends at the end.
Answer[1, 4, 2, 5, 8]
Common slips: One pass does not sort the list; it only moves the largest item into place.
Question 72
How many comparisons does bubble sort make on 5 items if it does not stop early?
Solution
1The passes compare 4, 3, 2 and 1 pairs.
24 + 3 + 2 + 1 = 10, which is n(n − 1)/2 with n = 5.
Answer10
Common slips: The count grows with n², so doubling the list roughly quadruples the work.
Question 73
A sorted list holds 16 items. What is the greatest number of comparisons binary search needs?
Solution
1Each comparison halves the list: 16, 8, 4, 2, 1.
2That is 5 looks: ⌊log2 16⌋ + 1 = 5.
Answer5
Common slips: The list must be sorted for binary search to work.
Question 74
A linear search for an item that is certainly present is equally likely to find it in any of 100 positions. Find the average number of comparisons.
Solution
1The number of comparisons is 1 to 100, equally likely.
2Average = (1 + 100) ÷ 2 = 50.5.
Answer50.5
Common slips: The average is not 100; that is the worst case.
Question 75
An O(n2) routine takes 2 s when n = 1000. Estimate the time when n = 3000.

Numerical methods

Questions 81–90. Iterate, bracket and step, and compare with the exact value.

Question 81
Use Newton’s method to find √2: xn+1 = (xn + 2/xn)/2, starting at x0 = 1. Find x2.
Solution
1x1 = (1 + 2/1)/2 = 1.5.
2x2 = (1.5 + 2/1.5)/2 = (1.5 + 1.3333)/2 = 1.41667.
3Exact √2 = 1.41421, so two steps are already accurate to 3 decimals.
Answer1.4167 (= 17/12)
Common slips: Each step roughly doubles the number of correct digits.
Question 82
Apply bisection to f(x) = x2 − 2 on [1, 2]. Give the interval after two steps.
Solution
1Step 1: midpoint 1.5, f(1.5) = 0.25 > 0, so the root is in [1, 1.5].
2Step 2: midpoint 1.25, f(1.25) = −0.4375 < 0, so the root is in [1.25, 1.5].
Answer[1.25, 1.5]
Common slips: Keep the half in which f changes sign.
Question 83
Bisection starts with an interval of length 1. How many steps guarantee an error below 0.001?
Solution
1After n steps the length is 1/2n.
22n > 1000 needs n ≥ 10 (210 = 1024).
Answer10
Common slips: Nine steps leave 1/512 = 0.00195, which is too large.
Question 84
Use the trapezoidal rule with 2 strips to estimate the integral of x2 from 0 to 2.
Solution
1h = 1. The values are f(0) = 0, f(1) = 1, f(2) = 4.
2T = (h/2)[f(0) + 2f(1) + f(2)] = 0.5(0 + 2 + 4) = 3.
3The exact value is 8/3 = 2.667, so the rule overestimates a curve that bends upward.
Answer3
Common slips: The middle value is counted twice.
Question 85
Use Simpson’s rule with 2 strips to estimate the integral of x2 from 0 to 2.
Solution
1h = 1, f(0) = 0, f(1) = 1, f(2) = 4.
2S = (h/3)[f(0) + 4f(1) + f(2)] = (1/3)(8) = 8/3.
3Simpson’s rule is exact for polynomials up to degree 3.
Answer8/3 ≈ 2.667
Common slips: The middle value has weight 4, not 2.
Question 86
Use Euler’s method for y′ = y, y(0) = 1, with step h = 0.5. Find y(1).
Solution
1yn+1 = yn + h·yn = 1.5yn.
2y(0.5) = 1.5 and y(1) = 2.25.
Answer2.25
Common slips: The exact answer is e = 2.718.
Question 87
For the same problem, find the error of Euler’s estimate at x = 1. (e = 2.71828.)
Solution
1Error = 2.71828 − 2.25 = 0.468.
2Halving the step to 0.25 would reduce the error roughly by half.
Answer≈ 0.468
Common slips: Euler’s method error is proportional to h.
Question 88

Question 91
Find the entry in row 1, column 2 of C = AB for A = [[1, 2], [3, 4]] and B = [[5, 6], [7, 8]].

Answer22

Question 94
Solve 2x + y = 5 and x − y = 1.
Solution
1Add the equations: 3x = 6, so x = 2.
2Put x = 2 in x − y = 1: y = 1.
3Check: 2(2) + 1 = 5.
Answerx = 2, y = 1

Question 95
Find the mean and the population standard deviation of the data.

print(st.mean(d), st.pstdev(d))
Solution
1Mean = 40 ÷ 8 = 5.
2Squared deviations: 9, 1, 1, 1, 0, 0, 4, 16, which add to 32.
3Variance = 32 ÷ 8 = 4, so the standard deviation is 2.
Answermean 5, standard deviation 2

Question 96
Fit y = mx + c by least squares through (1, 2), (2, 3), (3, 5).
Solution
1n = 3, Σx = 6, Σy = 10, Σxy = 2 + 6 + 15 = 23, Σx2 = 14.
2m = (nΣxy − ΣxΣy)/(nΣx2 − (Σx)2) = (69 − 60)/(42 − 36) = 1.5.
3c = (Σy − mΣx)/n = (10 − 9)/3 = 1/3.
Answery = 1.5x + 0.333
Common slips: The denominator is nΣx² − (Σx)², not Σx² − Σx.
